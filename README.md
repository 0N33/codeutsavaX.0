## 🌟 Why the "Code Comic" Theme?
For the landmark 10th edition of CodeUtsava, we reimagined the traditional hackathon website into an **interactive pop-art digital webcomic**:
- Hackathons are filled with high-energy stories: late-night debugging, sudden eureka moments, racing against the 36-hour clock, and the triumphant stage pitch.
- Inspired by the award-winning **Ponpon Mania** aesthetic, every commit is rendered like an inked comic panel, every runtime error is a comic supervillain, and every participant is a superhero builder.
- Blends retro comic ink outlines (`3px solid #18181B`), Ben-Day halftone patterns, organic cloud cutouts, procedural lo-fi synthesizer beats, and buttery 60 FPS spring animations.

## 🚀 Key Features & Interactive Architecture

### 1. Interactive Comic Intro Cover (Ponpon Mania Style)
- Vibrant manga cover with custom SVG character trio, animated skyline, spinning stamp badge, and floating interactive balloons.
- Clickable characters with dynamic speech bubbles.
- "READ COMIC NOW" & "ENTER HACKATHON ARENA" dual navigation paths.

### 2. Cloud-Cutout Comic Reader Mode (4 Interactive Issues)
- **Chapter 01**: *The 404 Anomaly & The Mysterious Invitation* (Decrypted NIT Raipur shortlist notice).
- **Chapter 02**: *The TCP Lab & Squad Assembly* (Arriving at NIT Raipur clock tower & TCP headquarters).
- **Chapter 03**: *36-Hour Sprint & The Boss Bug* (Interactive terminal mini-game to debug & squash runtime bugs).
- **Chapter 04**: *Victory & The Hackathon Arena* (Confetti celebration & stage pitch unlocking the ₹5,00,000+ prize pool).

### 3. Integrated Lo-Fi Audio Player Pill
- Procedural Web Audio API synthesizer looper with 3 tracks:
  - `01. lo-fi compiler beats (code & chill)`
  - `02. 36-hour midnight coffee rush`
  - `03. victory at nit raipur clock tower`
- Live equalizer visualizer, track skipping, sound effects toggle, and retro comic sound bursts (`*POW!*`, `*CLACK!*`, `*COMPILE!*`).

### 4. Spider-Verse & Pop-Art Landing Page
- **Hero Section**: Strong headline with real-time countdown to October 26, 2026.
- **About TCP & NIT Raipur**: 10-year legacy, statistics counters (1,500+ hackers, 50+ mentors).
- **6 Problem Tracks**: AI/Agentic ML, Web3 & DeFi (Polygon), FinTech, HealthTech, Hardware Edition, and Open Innovation.
- **Prizes & Loot**: ₹5,00,000+ prize breakdown, trophies, plus NIT Raipur free meals, hostel stay, and up to ₹1,500 travel reimbursement.
- **12-Stage Timeline**: Complete roadmap from registration to grand judgment.
- **Sponsors**: Devfolio, Polygon, ETHIndia, SBI, LIC, Fold Health.
- **Rules & Guidelines**: Mandatory team rules and code integrity guidelines.
- **FAQ Accordion**: Speech-bubble expandable answers.
- **Registration Modal**: Devfolio fast-track application form with instant ticket pass generator and confetti.
- **Footer**: Helpdesk coordination table and repository guidelines.

## 🛠️ Tech Stack
- **Framework**: React 18 + Vite
- **Styling**: Tailwind CSS (with custom comic design tokens, halftone patterns, and custom shadows)
- **Icons**: Lucide React + Handcrafted SVG Brand & Mascot Vectors
- **Sound Engine**: Web Audio API Procedural Chiptune / Lo-Fi Synthesizer
- **Animations & FX**: Canvas Confetti, CSS Keyframe Springs, Halftone Shaders
